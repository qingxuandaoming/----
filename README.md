# 辨体施膳 (健康管理)

## 项目简介
本项目是一款基于 Vue 3 + Vite + uni-app 框架开发的健康管理与中医体质辨识应用——**“辨体施膳”**。应用核心围绕中医体质测试及相关的健康饮食、膳食推荐，同时结合了电商功能的商品展示与购买，旨在为用户提供个性化、科学的健康管理方案。

## 核心功能与模块
- **首页与分类**：展示健康资讯、推荐食谱、相关商品分类等，引导用户快速定位需求。
- **体质测试模块**：包含“问卷测试”与“舌苔检测”，通过智能化与数据化手段分析用户体质并给出专业的“测试结果”与建议。
- **电商交易流程**：涵盖商品详情查看、全局搜索、购物车管理以及订单确认等完整的移动端购物闭环。
- **用户中心与营销平台**：提供个人资料管理（我的）、会员中心、积分商城等运营与用户留存功能。

## 技术栈与依赖
- **核心框架**：[Vue 3](https://v3.vuejs.org/)
- **跨端框架**：[uni-app](https://uniapp.dcloud.net.cn/) (支持 H5、App、小程序等多端编译)
- **构建工具**：[Vite](https://cn.vitejs.dev/)
- **UI 组件库**：[uview-plus](https://uiadmin.net/uview-plus/) (^3.1.23)
- **状态/国际化**：支持 Vue-i18n

## 运行与构建指引

进入主前端项目目录进行操作：
```bash
cd uni-app
```

### 1. 安装依赖
```bash
npm install
```

### 2. 本地开发调试 (H5)
项目提供了两套 H5 的调试方案，可根据开发需求选择：
```bash
# 方案 A: 标准 H5 启动
npm run dev:h5

# 方案 B: 极速 H5 启动 (跳过部分 uni-app 独有编译，速度更快，适用于纯页面 UI 调试)
npm run dev:h5:fast
```

### 3. Android 应用开发与打包
```bash
# 启动 Android 开发环境
npm run dev:app-android

# 构建 Android 生产环境发行包
npm run build:app-android
```
